正三角形的直观图面积怎么求？

抓住面积变化倍数：斜二测画法下，平面图形面积变为原面积的 √2 / 4。

题目

已知正三角形边长为 2，用斜二测画法画出该三角形的直观图，则所得直观图的面积为多少？

选项：A. √2 / 4　B. √6 / 4　C. 2√2　D. 2√6

答案：B. √6 / 4

图形理解

原正三角形

边长为 2，高为 √3，原面积为 √3。

斜二测直观图

纵向长度先减半，再按 45° 方向倾斜。

解题思路

  1. 先求原正三角形面积。
  2. 利用斜二测画法的面积变化倍数。
  3. 原面积乘以 √2 / 4，得到直观图面积。
S原 = (√3 / 4) × 2² = √3
S直观图 = S原 × (√2 / 4)
S直观图 = √3 × (√2 / 4) = √6 / 4

为什么乘 √2 / 4？

斜二测画法可以理解为两个变化：

  • 横向长度不变。
  • 纵向长度变成原来的 1 / 2，并且与横向成 45°。

面积由“底 × 高”决定，纵向变斜后，真正有效的垂直高度还要乘 sin45°。

面积倍率 = (1 / 2) × sin45° = (1 / 2) × (√2 / 2) = √2 / 4

快速解题模板

看到关键词：斜二测画法、直观图面积、平面图形。

立刻使用：

S直观图 = S原图 × √2 / 4

如果反过来问原图面积：

S原图 = S直观图 × 2√2

考察知识点

  • 正三角形面积公式：S = √3 / 4 × a²。
  • 斜二测画法规则：横不变，纵减半，纵轴与横轴成 45°。
  • 面积变化规律：直观图面积 = 原图面积 × √2 / 4。
  • 三角函数基础：sin45° = √2 / 2。

易错点

  • 误以为面积只变成一半。纵向长度是减半，但面积还要乘 sin45°。
  • 把斜线长度当作高。图中的斜方向长度不是三角形面积公式里的垂直高。
  • 正三角形面积算错。边长为 2 时，面积是 √3，不是 2 或 2√3。
  • 选项不做大小判断。直观图面积应小于原面积 √3，所以 2√2、2√6 这类偏大的选项可快速排除。

一句话记忆

斜二测面积：原图乘 √2 / 4；反求原图：直观图乘 2√2。
