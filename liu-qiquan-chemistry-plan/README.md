# 刘启权化学提升计划

这是一个可本地直接打开的静态学习系统，面向湖南高中化学约30分左右的基础薄弱学生。

## 给启权的话

启权，你其实很聪明，很多题不是你学不会，而是以前没有按适合自己的节奏一步一步搭起来。要相信自己，琳姐会帮你把难的地方拆小、讲清、练稳；只要你自己肯用心，每天踏踏实实看懂一点、做对一点、订正一点，化学一定会慢慢提上来。

## 使用方法

1. 打开 `index.html`。
2. 按章节进入知识讲解页或基础训练页。
3. 先看图，再学概念，再做基础题，最后保存错题复盘。

## 文件结构

- `index.html`：首页与章节导航
- `pages/`：28个学习页面
- `assets/css/style.css`：统一样式
- `assets/js/main.js`：学习进度、错题复盘、复制重点
- `data/chapters.json`：章节数据

## 学习建议

先从第1章、第2章、第3章和实验基础开始，不急着做综合压轴题。
