知识点拆解

电解质与非电解质

一句话解释：电解质是溶于水或熔融时能导电的化合物。

必须记住：酸、碱、盐、多数金属氧化物是电解质；蔗糖、酒精、CO2、SO2 等常见为非电解质。

容易混淆：单质和混合物既不是电解质，也不是非电解质。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

离子方程式

一句话解释：离子方程式只写真正参加反应的离子。

必须记住：强酸、强碱、可溶性盐要拆；沉淀、气体、水、弱酸弱碱、氧化物不拆。

容易混淆：不要把 CaCO3、BaSO4、H2O、CO2 这类物质拆成离子。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

离子共存

一句话解释：共存就是这些离子在同一溶液里不能明显反应。

必须记住：查四类：沉淀、气体、弱电解质、氧化还原；再看酸性、碱性、无色等附加条件。

容易混淆：看到 H+、OH-、Ba2+、Ag+、CO3^2-、SO4^2- 要格外小心。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

氧化还原

一句话解释：有化合价变化的反应就是氧化还原反应。

必须记住：升失氧还：化合价升高，失电子，被氧化，作还原剂；化合价降低，得电子，被还原，作氧化剂。

容易混淆：氧化剂本身被还原，还原剂本身被氧化，名称容易绕。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

核心公式 / 方程式卡片

  • 强酸强碱可溶盐拆成离子
  • 沉淀、气体、水、弱电解质不拆
  • 化合价升高：失电子，作还原剂
  • 化合价降低：得电子，作氧化剂
  • 得电子总数 = 失电子总数

基础例题讲解

例题1

NaCl 溶液与 AgNO3 溶液反应的离子方程式怎么写？

题干关键词考点方法答案
  1. 第一步：看关键词：NaCl、AgNO3、离子方程式
  2. 第二步：找知识点：离子反应
  3. 第三步：列方法：NaCl 和 AgNO3 都是可溶盐要拆，AgCl 是沉淀不拆。
  4. 第四步：写答案：答案：Ag+ + Cl- = AgCl↓。

易错提醒：基础题最怕跳过单位、条件和关键词。

例题2

Fe 与 CuSO4 溶液反应中，谁是还原剂？

题干关键词考点方法答案
  1. 第一步：看关键词：Fe、CuSO4、还原剂
  2. 第二步：找知识点：氧化还原
  3. 第三步：列方法：Fe 从 0 价升到 +2 价，失电子，被氧化。
  4. 第四步：写答案：答案：Fe 是还原剂。

易错提醒：基础题最怕跳过单位、条件和关键词。

例题3

H+、CO3^2- 能否大量共存？

题干关键词考点方法答案
  1. 第一步：看关键词：H+、CO3^2-、共存
  2. 第二步：找知识点：离子共存
  3. 第三步：列方法：H+ 与 CO3^2- 反应生成 CO2 和 H2O。
  4. 第四步：写答案：答案：不能大量共存。

易错提醒：基础题最怕跳过单位、条件和关键词。
