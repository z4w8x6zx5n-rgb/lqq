10道基础选择题

1. 下列属于电解质的是

  1. A. 铜
  2. B. NaCl
  3. C. 酒精
  4. D. 蔗糖溶液
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：NaCl 是化合物，水溶液或熔融时能导电。

2. 下列既不是电解质也不是非电解质的是

  1. A. HCl
  2. B. CO2
  3. C. Fe
  4. D. NaOH
查看答案与解析

答案：C

第一步：看题目关键词。

第二步：判断考点。

第三步：单质 Fe 不属于电解质或非电解质。

3. Ba2+ 与 SO4^2- 不能大量共存的原因是

  1. A. 生成气体
  2. B. 生成沉淀
  3. C. 发生燃烧
  4. D. 颜色相同
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：BaSO4 是难溶沉淀。

4. AgNO3 与 NaCl 反应的离子方程式是

  1. A. Ag+ + Cl- = AgCl↓
  2. B. Na+ + NO3- = NaNO3
  3. C. AgNO3 = Ag+ + NO3-
  4. D. NaCl = Na+ + Cl-
查看答案与解析

答案：A

第一步：看题目关键词。

第二步：判断考点。

第三步：真正反应的是 Ag+ 与 Cl-。

5. H+ 与 CO3^2- 不能大量共存，是因为会生成

  1. A. H2
  2. B. CO2 和 H2O
  3. C. O2
  4. D. NaCl
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：碳酸根遇酸生成二氧化碳和水。

6. 氧化还原反应的判断依据是

  1. A. 是否放热
  2. B. 是否有沉淀
  3. C. 是否有化合价变化
  4. D. 是否有水生成
查看答案与解析

答案：C

第一步：看题目关键词。

第二步：判断考点。

第三步：氧化还原看化合价是否变化。

7. 反应 Fe + Cu2+ = Fe2+ + Cu 中，还原剂是

  1. A. Fe
  2. B. Cu2+
  3. C. Fe2+
  4. D. Cu
查看答案与解析

答案：A

第一步：看题目关键词。

第二步：判断考点。

第三步：Fe 化合价升高，失电子，作还原剂。

8. 化合价降低的物质发生

  1. A. 氧化反应
  2. B. 还原反应
  3. C. 分解反应
  4. D. 复分解反应
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：降得还：化合价降低，得电子，被还原。

9. 下列离子在强酸性溶液中不能大量存在的是

  1. A. Na+
  2. B. Cl-
  3. C. NO3-
  4. D. CO3^2-
查看答案与解析

答案：D

第一步：看题目关键词。

第二步：判断考点。

第三步：CO3^2- 会与 H+ 反应。

10. 配平氧化还原方程式常用的核心思想是

  1. A. 质量越大越先配
  2. B. 得失电子守恒
  3. C. 颜色守恒
  4. D. 气体体积守恒
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：氧化还原配平抓电子守恒。

3道计算 / 表达题

1. 写出盐酸与 NaOH 溶液反应的离子方程式。

查看答案与解析

第一步：读题，找已知量和要求量。

第二步：选择对应公式或规律。

第三步：H+ + OH- = H2O。

2. 判断 Fe2+ 与 Cl2 反应中 Fe2+ 的作用。

查看答案与解析

第一步：读题，找已知量和要求量。

第二步：选择对应公式或规律。

第三步：Fe2+ 被氧化为 Fe3+，化合价升高，作还原剂。

3. 说明 H+、OH- 为什么不能大量共存。

查看答案与解析

第一步：读题，找已知量和要求量。

第二步：选择对应公式或规律。

第三步：H+ 与 OH- 反应生成水，离子浓度显著减小。
