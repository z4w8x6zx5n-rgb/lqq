知识点拆解

物质分类

一句话解释：先看是不是一种物质，再看是不是一种元素。

必须记住：纯净物只有一种物质；混合物有多种物质。单质必须是同一种元素组成的纯净物。

容易混淆：空气、矿泉水、合金是混合物；O2 和 O3 混在一起不是单质，而是混合物。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

胶体

一句话解释：胶体是分散质粒子直径在 1-100 nm 的分散系。

必须记住：胶体的本质区别是粒子直径，不是颜色。丁达尔效应是常考性质。

容易混淆：Fe(OH)3 胶体能产生丁达尔效应，但胶粒不一定都带电。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

物质的量

一句话解释：mol 是用来数微观粒子的单位。

必须记住：n=m/M，n=N/NA，气体可用 n=V/Vm。

容易混淆：标准状况下 22.4 L/mol 只给气体用，水、乙醇、苯、SO3 等不能乱套。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

物质的量浓度

一句话解释：c=n/V，表示 1 L 溶液中有多少 mol 溶质。

必须记住：V 是溶液体积，单位用 L；稀释前后溶质的物质的量不变。

容易混淆：100 mL 要写成 0.100 L，不能把 100 直接代入。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

核心公式 / 方程式卡片

  • n = m / M
  • n = N / NA
  • n = V气 / Vm
  • c = n / V
  • c浓V浓 = c稀V稀

基础例题讲解

例题1

18 g 水的物质的量是多少？

题干关键词考点方法答案
  1. 第一步：看关键词：18 g、水、物质的量
  2. 第二步：找知识点：物质的量计算
  3. 第三步：列方法：M(H2O)=18 g/mol，n=m/M=18/18=1 mol
  4. 第四步：写答案：答案：1 mol。注意摩尔质量单位是 g/mol。

易错提醒：基础题最怕跳过单位、条件和关键词。

例题2

100 mL 0.10 mol/L NaCl 溶液中 NaCl 的物质的量是多少？

题干关键词考点方法答案
  1. 第一步：看关键词：100 mL、0.10 mol/L
  2. 第二步：找知识点：浓度计算
  3. 第三步：列方法：V=0.100 L，n=cV=0.10x0.100=0.010 mol
  4. 第四步：写答案：答案：0.010 mol。先把 mL 换成 L。

易错提醒：基础题最怕跳过单位、条件和关键词。

例题3

标准状况下 2.24 L CO2 的物质的量是多少？

题干关键词考点方法答案
  1. 第一步：看关键词：标准状况、CO2、气体
  2. 第二步：找知识点：气体摩尔体积
  3. 第三步：列方法：CO2 是气体，可用 n=V/Vm=2.24/22.4=0.10 mol
  4. 第四步：写答案：答案：0.10 mol。若是水或苯就不能这样算。

易错提醒：基础题最怕跳过单位、条件和关键词。
