知识点拆解

钠及其化合物

一句话解释：钠很活泼，遇水剧烈反应生成 NaOH 和 H2。

必须记住：2Na + 2H2O = 2NaOH + H2↑；Na2O2 与水或 CO2 反应会放出 O2。

容易混淆：钠不能直接放空气中，实验取用要用镊子，保存于煤油中。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

铝及其化合物

一句话解释：铝、氧化铝、氢氧化铝都体现两性特点。

必须记住：Al(OH)3 能溶于强酸，也能溶于强碱；Al2O3 也有两性。

容易混淆：向铝盐中加 NaOH，少量生成沉淀，过量沉淀溶解。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

铁及其化合物

一句话解释：铁题核心是 Fe、Fe2+、Fe3+ 之间的转化。

必须记住：Fe3+ 遇 KSCN 显红色；Fe2+ 易被氧化，可先加 KSCN 不变红，再加氯水变红。

容易混淆：铁与盐酸生成 FeCl2，铁与氯气燃烧生成 FeCl3。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

颜色与现象

一句话解释：金属化合物题常用颜色和现象锁定物质。

必须记住：Fe(OH)2 白色沉淀迅速变灰绿再变红褐；Fe(OH)3 为红褐色沉淀。

容易混淆：写实验现象要写颜色变化、沉淀或气体，不能只写“反应了”。

考试怎么问：常用选择题、判断题或填空题考你能不能认出这个知识点。

基础例子：先把题干关键词圈出来，再套本块的判断方法。

核心公式 / 方程式卡片

  • 2Na + 2H2O = 2NaOH + H2↑
  • 2Na2O2 + 2H2O = 4NaOH + O2↑
  • Al(OH)3 + 3H+ = Al3+ + 3H2O
  • Al(OH)3 + OH- = [Al(OH)4]-
  • Fe3+ + 3SCN- 可形成红色络合物

基础例题讲解

例题1

钠投入水中会看到哪些现象？

题干关键词考点方法答案
  1. 第一步：看关键词：钠、水、现象
  2. 第二步：找知识点：钠的性质
  3. 第三步：列方法：从密度、熔点、反应放热、产物碱性四个角度描述。
  4. 第四步：写答案：答案：浮在水面，熔成小球，四处游动，有响声，滴酚酞后溶液变红。

易错提醒：基础题最怕跳过单位、条件和关键词。

例题2

向 AlCl3 溶液中逐滴加入 NaOH 至过量，现象是什么？

题干关键词考点方法答案
  1. 第一步：看关键词：AlCl3、NaOH、过量
  2. 第二步：找知识点：Al(OH)3 两性
  3. 第三步：列方法：先生成白色沉淀，NaOH 过量后沉淀溶解。
  4. 第四步：写答案：答案：先有白色沉淀，后沉淀逐渐溶解。

易错提醒：基础题最怕跳过单位、条件和关键词。

例题3

如何检验 Fe3+？

题干关键词考点方法答案
  1. 第一步：看关键词：Fe3+、检验
  2. 第二步：找知识点：铁离子检验
  3. 第三步：列方法：加入 KSCN 溶液，观察颜色。
  4. 第四步：写答案：答案：加入 KSCN 溶液，若溶液变红，说明含 Fe3+。

易错提醒：基础题最怕跳过单位、条件和关键词。
