10道基础选择题

1. 钠与水反应生成的气体是

  1. A. O2
  2. B. H2
  3. C. Cl2
  4. D. NH3
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：2Na + 2H2O = 2NaOH + H2↑。

2. 钠保存在煤油中的主要原因是

  1. A. 便于称量
  2. B. 防止与空气和水反应
  3. C. 提高密度
  4. D. 增加颜色
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：钠很活泼，要隔绝空气和水。

3. Na2O2 与水反应会生成

  1. A. NaOH 和 O2
  2. B. NaCl 和 H2
  3. C. Na2CO3 和 H2
  4. D. NaOH 和 CO2
查看答案与解析

答案：A

第一步：看题目关键词。

第二步：判断考点。

第三步：过氧化钠与水反应生成 NaOH 和 O2。

4. Al(OH)3 的重要性质是

  1. A. 只溶于酸
  2. B. 只溶于碱
  3. C. 既能溶于强酸也能溶于强碱
  4. D. 不反应
查看答案与解析

答案：C

第一步：看题目关键词。

第二步：判断考点。

第三步：Al(OH)3 是两性氢氧化物。

5. 向 AlCl3 溶液中加入过量 NaOH 的最终现象是

  1. A. 只生成沉淀
  2. B. 沉淀先生成后溶解
  3. C. 立刻产生气体
  4. D. 无现象
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：Al(OH)3 先沉淀，过量碱中溶解。

6. 检验 Fe3+ 常用的试剂是

  1. A. KSCN 溶液
  2. B. BaCl2 溶液
  3. C. 石蕊
  4. D. 淀粉溶液
查看答案与解析

答案：A

第一步：看题目关键词。

第二步：判断考点。

第三步：Fe3+ 遇 SCN- 显红色。

7. Fe(OH)2 在空气中最终变成

  1. A. 白色
  2. B. 红褐色 Fe(OH)3
  3. C. 蓝色沉淀
  4. D. 黑色气体
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：Fe(OH)2 易被氧化为 Fe(OH)3。

8. 铁与盐酸反应生成的铁盐中铁元素常为

  1. A. 0价
  2. B. +1价
  3. C. +2价
  4. D. +3价
查看答案与解析

答案：C

第一步：看题目关键词。

第二步：判断考点。

第三步：Fe 与非氧化性酸反应生成 Fe2+。

9. 铁在氯气中燃烧主要生成

  1. A. FeCl2
  2. B. FeCl3
  3. C. FeO
  4. D. Fe(OH)3
查看答案与解析

答案：B

第一步：看题目关键词。

第二步：判断考点。

第三步：氯气氧化性强，生成 FeCl3。

10. 写实验现象时最不应该只写

  1. A. 颜色变化
  2. B. 沉淀颜色
  3. C. 有气泡
  4. D. 发生反应
查看答案与解析

答案：D

第一步：看题目关键词。

第二步：判断考点。

第三步：现象要具体，不能只写“发生反应”。

3道计算 / 表达题

1. 写出钠与水反应的化学方程式。

查看答案与解析

第一步：读题，找已知量和要求量。

第二步：选择对应公式或规律。

第三步：2Na + 2H2O = 2NaOH + H2↑。

2. 写出 Al(OH)3 溶于盐酸的离子方程式。

查看答案与解析

第一步：读题，找已知量和要求量。

第二步：选择对应公式或规律。

第三步：Al(OH)3 + 3H+ = Al3+ + 3H2O。

3. 如何用实验语言检验 Fe3+？

查看答案与解析

第一步：读题，找已知量和要求量。

第二步：选择对应公式或规律。

第三步：取少量待测液于试管中，滴加 KSCN 溶液，若溶液变红，说明含 Fe3+。
