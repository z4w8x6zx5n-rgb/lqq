高中数学向量详细图解讲义

依据新增的 2026 高三一轮复习专项资料重新整理：平面向量的线性运算、基本定理、数量积、坐标运算、新定义问题，以及空间向量和圆锥曲线中的向量问题。所有容易显示不清的符号都附了括号文字说明。

先把符号说清楚

网页或手机里有时箭头符号显示不完整，所以本讲义采用“符号 + 括号备注”的方式。

写法含义口头理解
AB（向量 AB）从 A 点指向 B 点的向量从 A 走到 B 的位移
|a|（向量 a 的模）向量 a 的长度箭头有多长
a·b（a 点乘 b，数量积）|a||b|cosθ，其中 θ 是 a 与 b 的夹角一个向量在另一个方向上的“贡献”
a ∥ b（a 平行 b）两个向量方向相同或相反共线，不一定同向
a ⟂ b（a 垂直 b）a·b=0夹角 90 度
学习主线：先画箭头，再写坐标；先看几何关系，再用公式验证。向量题最怕一上来乱算，先看“平行、垂直、夹角、长度、面积、定值”是哪一种。

一、向量概念：向量是“带方向的长度”

向量既有大小又有方向。例如从 A 到 B 的箭头叫 AB（向量 AB）。向量不固定在某个位置，平移后只要长度和方向不变，仍是同一个向量。

相等向量：长度相等，方向相同。
相反向量：长度相等，方向相反。
零向量 0：长度为 0，方向不讨论。
易错点：“长度相等”不能推出向量相等；“方向相同”也不能推出向量相等。必须长度和方向同时满足。

向量看“走法”，不看箭头画在纸上的位置。

二、线性运算：加、减、数乘

加法

首尾相接：先走 a，再走 b，总效果是 a+b。若 AB=a，BC=b，则 AC=a+b。

减法

a-b 等于 a+(-b)。两个向量同起点时，从 b 的终点指向 a 的终点，就是 a-b。

数乘

ka 表示把 a 伸缩 |k| 倍。k 大于 0 同向，k 小于 0 反向，k 等于 0 得零向量。

例题：平行四边形中的线性运算

在平行四边形 ABCD 中，E 是 CD 的中点。设 AB=a，AD=b，求 BE（向量 BE）。

第一步：找一条从 B 到 E 的路。可以走 B→C→E，所以 BE=BC+CE。

第二步：把每一段换成 a、b。BC=AD=b；CD 与 AB 方向相反，所以 CD=-a，E 是 CD 中点，所以 CE=(1/2)CD=-(1/2)a。

第三步：合并。BE=b-(1/2)a，即 BE=-(1/2)a+b。

这里的 (1/2)a 表示“a 的一半”。

三、平面向量基本定理：把所有向量拆成两个方向

如果 e1、e2 是平面内两个不共线向量，那么任何一个平面向量 p 都能唯一写成 p=xe1+ye2（x、y 是实数）。这就是“选两根不平行的尺子量全平面”。

平面向量基本定理：p = x e1 + y e2。
括号备注：x e1 表示沿 e1 方向走 x 倍，y e2 表示沿 e2 方向走 y 倍。
常见题型：求交点 F 的向量表达式
  1. 选两个基底：常选 AB、AD 或 AB、AC。
  2. 从不同路径表示同一个向量，例如 AF。
  3. 因为基底不共线，所以对应系数相等。
  4. 解出比例，再回代。
易错点：看到“中点、三等分点、重心、交点”，不要只靠图猜比例。向量表达式的系数要通过路径相等或相似关系得到。

四、坐标运算：把图变成数

坐标是向量题最稳定的工具。点 A(x1,y1)、B(x2,y2)，则 AB=(x2-x1,y2-y1)。括号备注：前一个数是横向变化，后一个数是纵向变化。

目标公式注意
由两点求向量AB=(xB-xA, yB-yA)终点减起点，顺序不能反。
求长度|a|=sqrt(x²+y²)sqrt 表示开平方。
判断共线x1y2-x2y1=0也可看是否 a=kb。
面积S三角形=1/2 |x1y2-x2y1|两个向量要从同一个顶点出发。

例题：三点共线

已知 A(1,2)，B(4,8)，C(0,0)，判断 A、B、C 是否共线。

第一步：从同一点出发取两个向量。CA=(1,2)，CB=(4,8)。

第二步：判断是否成倍数。CB=4CA 吗？4CA=(4,8)，正好等于 CB。

结论：CA 与 CB 共线，且有公共点 C，所以 A、B、C 三点共线。

易错提醒：只说两个向量共线还不够，三点共线要说明它们有公共点或来自同一个起点。

五、数量积：夹角、垂直、投影的总开关

a·b = |a||b|cosθ。
坐标形式：若 a=(x1,y1)，b=(x2,y2)，则 a·b=x1x2+y1y2。
看到题目问优先想到
垂直a·b=0
夹角cosθ=(a·b)/(|a||b|)
锐角或钝角a·b 大于 0 为锐角，小于 0 为钝角，等于 0 为直角
投影b 在 a 方向上的投影长度 = (a·b)/|a|
易错点：a·b 是数量，不是向量；夹角 θ 默认取 0° 到 180°。求线线角时有时要取锐角，要看题目语境。

例题：求夹角

已知 a=(1,sqrt(3))，b=(2,0)，求 a 与 b 的夹角。

第一步：算数量积。a·b=1×2+sqrt(3)×0=2。

第二步：算长度。|a|=sqrt(1²+(sqrt(3))²)=2，|b|=2。

第三步：代入 cosθ=(a·b)/(|a||b|)=2/(2×2)=1/2。

第四步：θ=60°。括号备注：cos60°=1/2。

六、各类题型分析与解题思路

题型 1：线性运算

信号：平行四边形、中点、交点、比例。
思路：选路线，拆成已知向量，利用中点或比例换系数。

题型 2：基本定理

信号：用 AB、AC 表示某向量。
思路：选不共线基底，写两种表达式，比较系数。

题型 3：坐标运算

信号：给点坐标，求长度、面积、共线。
思路：终点减起点，统一转成坐标公式。

题型 4：数量积

信号：垂直、夹角、投影、最值。
思路：先算 a·b，再联系 cosθ 或 a·b=0。

题型 5：新定义

信号：题目临时定义一种运算。
思路：逐字翻译定义，把新符号还原成坐标或数量积。

题型 6：圆锥曲线向量

信号：椭圆/双曲线中出现 MA·MB=0、向量共线、定点定值。
思路：设点坐标，联立韦达，向量条件转代数。

圆锥曲线向量题的通用模板

  1. 设直线或点坐标。例如 A(x1,y1)、B(x2,y2)。
  2. 联立曲线方程，得到关于 x 的二次方程。
  3. 用韦达定理写 x1+x2、x1x2。括号备注：韦达就是二次方程两根和、两根积。
  4. 把向量条件翻译成代数条件：MA·MB=0 表示垂直；MA=λMB 表示共线或比例。
  5. 整理出定点、定值或参数关系。
易错点：圆锥曲线题里“向量”只是条件翻译器，真正计算常靠联立方程和韦达定理。不要只停留在画箭头。

七、空间向量：立体几何的坐标化

空间向量把平面坐标 (x,y) 扩展成 (x,y,z)。新增资料中的空间向量专项主要考：线线角、线面角、二面角、空间距离、最值与范围。

空间数量积：a·b=x1x2+y1y2+z1z2。
空间长度：|a|=sqrt(x²+y²+z²)。
问题向量做法
线线角取两条直线的方向向量，用 cosθ=|a·b|/(|a||b|)。
线面角取直线方向向量 v 和平面法向量 n，先算 v 与 n 的夹角，再转成线面角。
二面角求两个面的法向量 n1、n2，再求法向量夹角。
点到面距离距离=|向量 AP · 法向量 n|/|n|。
空间向量题一步一步走：
  1. 建系：优先把互相垂直的棱当 x、y、z 轴。
  2. 写点：把题中关键点的坐标写出来，中点用平均数。
  3. 写向量：线用方向向量，面用法向量。
  4. 套公式：垂直用点乘为 0，角度用 cos 公式，距离用投影公式。
  5. 检查角：二面角有时要取补角，答案要符合题意。

例题：判断空间向量垂直

已知 u=(1,-2,2)，v=(2,1,0)，判断 u 与 v 是否垂直。

u·v=1×2+(-2)×1+2×0=2-2+0=0，所以 u ⟂ v（u 垂直 v）。

注意：空间向量也一样用数量积判断垂直，只是多了 z 坐标。

考点必须掌握常见坑
概念相等、相反、零向量只看长度，不看方向。

基本定理用两个不共线向量表示其他向量基底共线导致不能比较系数。
坐标长度、共线、面积AB 写成 A-B 而不是 B-A。
数量积垂直、夹角、投影忘记除以 |a||b|。
