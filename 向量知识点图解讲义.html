高中数学向量知识点图解讲义

给高中生看的向量入门到高考基础：把向量当成“带方向的位移”，先看图，再落到公式。每一批都有图形、通俗解释、例题和详细解答。

建议学习节奏：每天 1 到 2 批，先遮住答案自己算，再看详解。

第一批：向量是什么 第二批：加减与数乘 第三批：坐标表示 第四批：数量积 第五批：几何应用 第六批：空间向量

第一批：向量是什么

向量就是既有大小又有方向的量。最常见的理解：从点 A 走到点 B，这一段“怎么走”的信息就是向量 AB。

向量 AB：起点 A，终点 B
长度 |AB|：这支箭头的长短
零向量 0：长度为 0，方向不确定

两个向量相等，不看它们画在哪里，只看长度是否相等、方向是否相同。所以同一支箭头平移到别处，仍是同一个向量。

记忆句：点有位置，向量重“走法”。一支箭头搬家以后，走法不变。

相等向量：方向相同、长度相等，起点在哪里不重要。

例题 1

在平行四边形 ABCD 中，判断向量 AB 与向量 DC 是否相等？向量 AD 与向量 BC 是否相等？

解：平行四边形的对边平行且相等。

向量 AB 的方向是 A 到 B；向量 DC 的方向是 D 到 C。二者方向相同、长度相等，所以 AB = DC。

向量 AD 的方向是 A 到 D；向量 BC 的方向是 B 到 C。二者方向相同、长度相等，所以 AD = BC。

第二批：向量加法、减法与数乘

1. 加法：首尾相接

先走向量 a，再走向量 b，总效果就是 a + b。画图时把第二支箭头的起点接到第一支箭头的终点。

若 A -> B 是 a，B -> C 是 b，则 A -> C 是 a + b

2. 减法：共同起点，看终点

a - b 可以理解成 a + (-b)。如果 a、b 从同一点出发，那么 b 的终点指向 a 的终点，就是 a - b。

3. 数乘：伸缩或反向

ka 表示把 a 的长度变成 |k| 倍。k 大于 0 同向，k 小于 0 反向，k 等于 0 变成零向量。

例题 2

已知向量 a = (2, -1)，b = (-3, 4)，求 2a - b。

解：先数乘，再相减。

2a = 2(2, -1) = (4, -2)。

2a - b = (4, -2) - (-3, 4) = (4 + 3, -2 - 4) = (7, -6)。

第三批：坐标表示，把图变成数

在平面直角坐标系中，一个向量可以写成 (x, y)。x 表示水平走多少，y 表示竖直走多少。

若 A(x1, y1)，B(x2, y2)，则 AB = (x2 - x1, y2 - y1)
|a| = √(x² + y²)

坐标法的好处是：加减、数乘、长度都能直接算。

运算坐标规则
a + b(x1 + x2, y1 + y2)
a - b(x1 - x2, y1 - y2)
ka(kx, ky)
|a|√(x² + y²)

从 A 到 B：横坐标相减得 3，纵坐标相减得 2。

例题 3

已知 A(2, -1)，B(-1, 3)，求向量 AB 及它的长度。

解：AB = (xB - xA, yB - yA) = (-1 - 2, 3 - (-1)) = (-3, 4)。

|AB| = √[(-3)² + 4²] = √25 = 5。

第四批：数量积，判断角度的核心工具

数量积也叫点积。它把两个向量变成一个数，用来处理夹角、垂直、投影等问题。

a·b = |a||b|cos θ
若 a=(x1,y1)，b=(x2,y2)，则 a·b = x1x2 + y1y2
结论判断方式
a 与 b 垂直a·b = 0
夹角为锐角a·b > 0
夹角为钝角a·b < 0
求夹角cos θ = (a·b)/(|a||b|)
易错点：a·b 是一个数，不是向量；|a·b| 和 |a||b| 不是一回事。

例题 4

已知 a = (1, 2)，b = (3, -1)，求 a·b，并判断 a 与 b 的夹角是锐角、直角还是钝角。

解：a·b = 1×3 + 2×(-1) = 3 - 2 = 1。

因为 a·b > 0，所以 cos θ > 0，夹角 θ 为锐角。

第五批：向量在几何中的常见用法

共线

若 a = λb，则 a 与 b 共线。坐标中可用 x1y2 - x2y1 = 0 判断。

中点

若 M 是 AB 中点，则 M((xA+xB)/2, (yA+yB)/2)。也可写 AM = MB。

垂直

两向量垂直的坐标条件：x1x2 + y1y2 = 0。

面积

平行四边形面积 = |x1y2 - x2y1|，三角形面积取一半。

例题 5

已知 A(0,0)，B(4,1)，C(1,3)，求三角形 ABC 的面积。

解：取 AB=(4,1)，AC=(1,3)。

平行四边形面积 = |4×3 - 1×1| = |12 - 1| = 11。

三角形 ABC 面积是它的一半，所以 S = 11/2。

第六批：空间向量，立体几何的计算语言

空间向量就是把平面中的 (x, y) 扩展成 (x, y, z)。它常用于证明线线垂直、线面垂直、求夹角和距离。

a=(x1,y1,z1)，b=(x2,y2,z2)
a·b=x1x2+y1y2+z1z2
|a|=√(x1²+y1²+z1²)

做题流程：

  1. 建立空间直角坐标系，优先把垂直的棱当坐标轴。
  2. 写出关键点坐标。
  3. 把线段、法向量转成坐标向量。
  4. 用数量积处理垂直、夹角、距离。

例题 6

在空间中，a=(1,2,2)，b=(2,-1,0)。判断 a 与 b 是否垂直。

解：计算数量积：a·b = 1×2 + 2×(-1) + 2×0 = 2 - 2 + 0 = 0。

数量积为 0，所以 a ⟂ b。

最后的复习清单

必须会自查问题
向量概念能不能说清“相等向量”和“相反向量”？
线性运算会不会画首尾相接、平行四边形法则？
坐标表示会不会由两点坐标写出向量坐标？
数量积能不能用 a·b=0 判断垂直，用公式求夹角？
综合应用会不会用共线、垂直、面积公式解决几何题？
空间向量能不能建系、写坐标、算数量积？
